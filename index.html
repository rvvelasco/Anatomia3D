Cómo usar Anatomía 3D

🖱️ Mover el modelo

Arrastra para girar, rueda o pellizco para acercar, clic derecho o dos dedos para desplazar.

👆 Seleccionar

Toca una estructura del modelo o de la lista. Doble toque para acercarte a ella.

🎨 Colores

seleccionado · origen · inserción · articulación.

🧅 Capas

Retira la capa superficial para ver los músculos profundos, o vuelve transparentes los músculos.

📘 Lecciones

Recorridos guiados con trucos para memorizar (manguito rotador, cuádriceps, carpo…).

⚡ Nervios

Elige un nervio y verás todos los músculos que inerva y qué ocurre si se lesiona.

🎓 Estudiar

Identificar, localizar, preguntas tipo test y fichas con repaso espaciado.

⌨️ Atajos

/ buscar · Esc deseleccionar · ←→ pasos de lección · F centrar · H ocultar.

Modelo anatómico esquemático generado por código con fines de estudio: las formas son simplificadas. Los datos siguen la terminología anatómica estándar; contrasta siempre con tu atlas de referencia. Tus notas, progreso y fichas se guardan solo en este navegador.
